# HomogeNets

Numerical **Homogen**ization with Neural **Nets**

## Getting Started
This project uses [uv](https://docs.astral.sh/uv/) package manager. To get started,
clone this repo

```
git clone https://github.com/MCMB-Lab/HomogeNets.git
cd HomogeNets
```
and setup the development environment
```
uv sync
```
and run an example
```
uv run python main.py
```
